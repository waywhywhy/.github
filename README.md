# waywhywhy/.github

Organisation-wide files for the waydlp project.

To install waydlp on Windows or Linux from your terminal, see the [install commands on our organisation profile](profile/README.md#install).

| Path | Purpose |
|---|---|
| `profile/README.md` | The organisation profile shown on github.com/waywhywhy |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` | Default community health files for repositories without their own |
| `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` | Default issue forms and pull request template |
| `workflow-templates/` | Starter workflows offered under *Actions > New workflow* in each repository |
| `.github/workflows/` | Reusable workflows (`workflow_call`) shared by the repositories |
| `BRANDING.md` | Name, colours and logo usage |

There is no `FUNDING.yml` because the project has no funding accounts yet. Add one once it does.
