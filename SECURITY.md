# Security policy

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues, discussions or pull requests.**

Use GitHub's private vulnerability reporting for the affected repository:

| Repository | Report privately |
|---|---|
| Desktop app, CLI, installers | <https://github.com/waywhywhy/waydlp-desktop-rust/security/advisories/new> |
| Android app | <https://github.com/waywhywhy/waydlp-mobile-dart/security/advisories/new> |
| Website | <https://github.com/waywhywhy/waywhy-website/security/advisories/new> |

Please include:

* a description of the problem and its impact,
* steps or a proof of concept to reproduce it,
* the affected version(s) and platform,
* any suggested fix.

## What to expect

* An acknowledgement within 7 days.
* An assessment, and a timeline for a fix agreed with you.
* Credit in the release notes if you'd like it.

Please give us reasonable time to release a fix before you disclose publicly.

## Supported versions

Security fixes are released for the latest version of each app.

## Out of scope

Vulnerabilities in yt-dlp or FFmpeg themselves should go to those projects. Reports that a website can be downloaded from aren't vulnerabilities in waydlp.
