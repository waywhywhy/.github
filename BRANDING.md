# waydlp branding

* **Name:** always lowercase `waydlp`, including at the start of a sentence.
* **Tagline:** *Your media, your format, your way.*
* **App ID:** `io.github.waywhywhy.waydlp`, used for the desktop Flatpak/AppStream ID and the Android application ID. It can be verified through the GitHub organisation; the project doesn't own a `waydlp.com` domain.
* **Logo:** a "w" wave landing on a baseline (the download-to-disk metaphor), inside a rounded square with a purple gradient ring on true black. The master file is [`profile/logo.svg`](profile/logo.svg), which is identical to `assets/icons/waydlp.svg` in waydlp-desktop-rust.

Use true black backgrounds, rounded corners (10 to 14 px) and purple only for emphasis. Keep glow and blur effects subtle.

Please don't use the name or logo in a way that suggests a fork or another product is the official waydlp.
