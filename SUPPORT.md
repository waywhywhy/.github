# Getting help

* **How do I...?** Read the documentation in [waywhy-website/content/docs](https://github.com/waywhywhy/waywhy-website/tree/main/content/docs), especially *Getting started* and *Troubleshooting*.
* **A site stopped working.** Update yt-dlp inside waydlp first. If plain `yt-dlp` fails too, report it to [yt-dlp](https://github.com/yt-dlp/yt-dlp/issues).
* **Found a bug?** Open an issue in the matching repository using the templates.
* **Security problem?** Follow the [security policy](SECURITY.md). Never use public issues for it.
